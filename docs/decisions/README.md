# Architecture Decision Records

ADRs capture decisions that are cross-cutting, security/privacy relevant, expensive to reverse, or contract breaking.

## Process

1. Copy `template.md` to `NNNN-short-title.md`.
2. Mark it `Proposed` and describe options, evidence, and consequences.
3. Obtain owner/architecture approval before dependent implementation.
4. Set status to `Accepted`, `Rejected`, or `Deferred`.
5. Never erase accepted history. A later ADR may mark it `Superseded by ADR-NNNN`.
6. Update master context, architecture, contracts, phases, and status as needed.

Number ADRs sequentially. Dates use ISO 8601.
